## ภาพอธิบายแบบอินเทอร์แอกทีฟ

มี 21 โมดูล เช่น

| โมดูล | ทำอะไรได้ |
|---|---|
| `powers`, `scinot` | เลื่อนเลขชี้กำลัง ดูการเติบโตและสเกลลอการิทึม |
| `prismnet`, `cylnet` | **คลี่รูปทรง** ออกเป็นรูปคลี่แบบเคลื่อนไหว |
| 3D (`viz3d.js`) | ปริซึมและทรงกระบอกหมุนได้ ปรับมิติ ผ่าครึ่ง อ่านค่าพื้นที่ผิว/ปริมาตรสด ๆ |
| `parallel`, `extangle` | ลากเส้นตัด/จุดยอด ดูคู่มุมที่เท่ากันเสมอ |
| `transform`, `tessel` | เล่นภาพเคลื่อนไหวการเลื่อน สะท้อน หมุน และการปูระนาบ |
| `congruence` | กด "ทับรูป" เพื่อเลื่อนสามเหลี่ยมไปทับอีกรูป ตามเงื่อนไข ด.ด.ด./ด.ม.ด./… |
| `proof` | **ไล่ขั้นการพิสูจน์** รูปและตารางเหตุผลเปิดเผยพร้อมกัน |
| `menelaus`, `arearatio`, `centroid`, `incircle` | ลากจุด ดูอัตราส่วนที่คงที่ |
| `inscribed`, `chordperp`, `tangentchord`, `cyclicquad` | ทฤษฎีบทวงกลมแบบลากได้ |
| `statviz`, `graphlab` | สลับค่ากลาง / ปรับสัมประสิทธิ์กราฟ |

ทุกภาพเป็น **SVG ที่สมบูรณ์ตั้งแต่ตอนเสิร์ฟ** — ปิด JavaScript แล้วยังอ่านรู้เรื่องครบ
JavaScript ทำหน้าที่เพิ่มการโต้ตอบเท่านั้น และเคารพ `prefers-reduced-motion`

## การแก้ไขเนื้อหา

เนื้อหาอยู่ใน `tools/content/*.py` ไฟล์ละหนึ่งบท แก้แล้วสั่ง build ใหม่

```bash
python tools/build.py
```

ไม่ต้องติดตั้งอะไรเพิ่ม (ใช้ Python มาตรฐานล้วน ไม่มี dependency)
ไฟล์ HTML ที่ได้ถูก commit ไว้ด้วย GitHub Pages จึงเสิร์ฟได้ทันที

### รูปแบบของโจทย์หนึ่งข้อ

```python
dict(lvl="hard",            # "med" | "hard" | "apply"
     tag="เมเนลอส",          # ป้ายหัวข้อย่อย (ไม่บังคับ)
     q=r"""โจทย์ ... \(x^2\) ...""",
     sol=r"""เฉลย ...""")
```

## สิ่งที่ใช้จากภายนอก

| สิ่ง | ใช้ทำอะไร | ถ้าโหลดไม่ได้ |
|---|---|---|
| MathJax 3 (CHTML) | เรนเดอร์สูตรคณิตศาสตร์ | เห็นเป็น LaTeX ดิบ ยังอ่านได้ |
| Three.js | โมเดล 3 มิติในบทพื้นที่ผิว/ปริมาตร | แสดงภาพ SVG สามมิติแทนอัตโนมัติ |
| Google Fonts | IBM Plex Sans Thai · Noto Serif Thai · IBM Plex Mono | ใช้ฟอนต์ระบบแทน |

ใช้ CHTML ไม่ใช่ SVG output ของ MathJax เพราะ SVG renderer ไม่มี glyph ภาษาไทย
และทำให้สระ/วรรณยุกต์ใน `\text{...}` แตกออกจากกัน
