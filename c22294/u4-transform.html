เครื่องมือการแปลงในโปรแกรม

โปรแกรมเรขาคณิตพลวัตมีเครื่องมือการแปลงที่สร้าง วัตถุตาม (dependent object) ขึ้นมา ภาพที่ได้จะขยับตาม ต้นแบบและตามวัตถุอ้างอิง (เส้นสะท้อน จุดหมุน เวกเตอร์) เองโดยอัตโนมัติ

เครื่องมือต้องเลือกสิ่งที่เปลี่ยนได้ภายหลัง
สะท้อนรอบเส้นวัตถุ แล้วเส้นสะท้อนลากเส้นสะท้อน → ภาพขยับตามทันที
สะท้อนรอบจุดวัตถุ แล้วจุดเทียบเท่าการหมุน \(180^\circ\) รอบจุดนั้น
หมุนรอบจุดวัตถุ จุดหมุน แล้วใส่ขนาดมุมใส่มุมเป็นตัวเลขหรือ ตัวเลื่อน (slider) เพื่อทำภาพเคลื่อนไหว
เลื่อนขนานด้วยเวกเตอร์วัตถุ แล้วเวกเตอร์ลากปลายเวกเตอร์ → ภาพเลื่อนตาม
ย่อ–ขยายจากจุดวัตถุ จุด แล้วอัตราส่วนไม่ รักษาระยะ — รูปคล้ายแต่ไม่เท่ากันทุกประการ
สิ่งที่การแปลงแต่ละแบบรักษาไว้
การแปลงความยาว มุมพื้นที่ทิศการเรียง
เลื่อนขนาน✓✓✓✓ คงเดิม
หมุน✓✓✓✓ คงเดิม
สะท้อน✓✓✓ ✗ กลับด้าน
ย่อ–ขยายอัตราส่วน \(k\)\(\times|k|\)✓ \(\times k^{2}\)คงเดิมถ้า \(k>0\)

สามแบบแรกเรียกรวมว่า การแปลงที่รักษาระยะ (isometry) และให้รูปที่เท่ากันทุกประการกับต้นแบบ

การประกอบการแปลง

กฎการประกอบที่ควรจำ
  1. สะท้อนรอบเส้นขนานสองเส้น ที่ห่างกัน \(d\) = เลื่อนขนาน ระยะ \(2d\) ในแนวตั้งฉากกับเส้นทั้งสอง
  2. สะท้อนรอบเส้นสองเส้นที่ตัดกัน เป็นมุม \(\theta\) = หมุน รอบจุดตัดเป็นมุม \(2\theta\)
  3. หมุนสองครั้ง รอบจุดเดียวกันด้วยมุม \(\alpha,\beta\) = หมุนมุม \(\alpha+\beta\)
  4. หมุนรอบจุดต่างกัน ด้วยมุม \(\alpha,\beta\) = หมุนมุม \(\alpha+\beta\) รอบจุดใหม่ (หรือเลื่อนขนาน ถ้า \(\alpha+\beta\) เป็นตัวคูณของ \(360^\circ\))
  5. สะท้อนจำนวนคู่ → รักษาทิศการเรียง; จำนวนคี่ → กลับทิศการเรียง
ตัวอย่าง 1ยากประกอบการแปลง
ใน GeoGebra สะท้อนรูปสามเหลี่ยมรอบเส้น \(x=1\) ได้รูปที่สอง แล้วสะท้อนรูปที่สองรอบเส้น \(x=5\) ได้รูปที่สาม
(ก) รูปที่สามเกิดจากรูปแรกด้วยการแปลงอะไร
(ข) ถ้าจุด \(A(3,4)\) อยู่ในรูปแรก \(A''\) อยู่ที่ใด
(ค) ทิศการเรียงจุดยอดของรูปที่สามเทียบกับรูปแรกเป็นอย่างไร

แนวคิดและวิธีทำ

  1. (ก) สะท้อนรอบเส้นขนานสองเส้นที่ห่างกัน \(d=5-1=4\) → เลื่อนขนานระยะ \(2d=8\)
  2. ทิศทาง: จากเส้นแรกไปเส้นที่สอง คือทาง \(+x\) ดังนั้นเวกเตอร์ \(=\langle8,0\rangle\)
  3. (ข) สะท้อนรอบ \(x=1\): \((x,y)\to(2-x,y)\) ได้ \(A'(-1,4)\)
  4. สะท้อนรอบ \(x=5\): \((x,y)\to(10-x,y)\) ได้ \(A''(11,4)\)
  5. ตรวจ: \(A''=A+\langle8,0\rangle=(3+8,4)=(11,4)\) ✓
  6. (ค) สะท้อนสองครั้ง (จำนวนคู่) → ทิศการเรียงคงเดิม

(ก) เลื่อนขนาน \(\langle8,0\rangle\) (ข) \(A''(11,4)\) (ค) คงเดิม

ตัวอย่าง 2ยากสไลเดอร์
สร้างรูปสามเหลี่ยมใน GeoGebra แล้วหมุนด้วยมุมที่ผูกกับตัวเลื่อน \(\alpha\) ที่เลื่อนได้ \(0^\circ\) ถึง \(360^\circ\)
(ก) เมื่อ \(\alpha=0^\circ\) ภาพอยู่ที่ใด
(ข) ภาพจะทับต้นแบบพอดีเมื่อ \(\alpha\) เท่าใด ถ้าต้นแบบเป็น รูปสามเหลี่ยมด้านเท่า
(ค) ถ้าต้นแบบเป็นรูปสามเหลี่ยมด้านไม่เท่า ภาพทับต้นแบบ เมื่อ \(\alpha\) เท่าใด

แนวคิดและวิธีทำ

  1. (ก) \(\alpha=0^\circ\) คือหมุนศูนย์องศา ภาพ ทับต้นแบบพอดี
  2. (ข) สามเหลี่ยมด้านเท่ามีสมมาตรแบบหมุนอันดับ 3 เมื่อจุดหมุนอยู่ที่จุดศูนย์กลางของรูป
  3. ภาพทับต้นแบบเมื่อ \(\alpha=0^\circ,120^\circ,240^\circ,360^\circ\)
  4. ข้อสำคัญ: ถ้าจุดหมุนไม่ได้อยู่ที่จุดศูนย์กลางรูป ภาพจะทับต้นแบบเฉพาะ \(\alpha=0^\circ\) และ \(360^\circ\) เท่านั้น
  5. (ค) สามเหลี่ยมด้านไม่เท่ามีสมมาตรแบบหมุนอันดับ 1 จึงทับเฉพาะ \(\alpha=0^\circ\) และ \(360^\circ\)

(ข) \(0^\circ,120^\circ,240^\circ,360^\circ\) (เมื่อหมุนรอบจุดศูนย์กลาง)  (ค) \(0^\circ\) และ \(360^\circ\)

เทเซเลชัน

เงื่อนไขการปูระนาบ

รูปหลายเหลี่ยมปูระนาบได้เมื่อมุมที่มาชุมนุมรอบจุดหนึ่ง รวมกันได้ \(360^\circ\) พอดี โดยไม่มีช่องว่างและไม่ทับกัน

ปูได้แน่นอน

  • รูปสามเหลี่ยม ทุกรูป — สำเนาที่หมุน \(180^\circ\) ประกบกันเป็นสี่เหลี่ยมด้านขนาน
  • รูปสี่เหลี่ยม ทุกรูป (แม้เว้า) — หมุน \(180^\circ\) รอบจุดกึ่งกลางของแต่ละด้าน มุมทั้งสี่มาชุมนุมรอบจุดเดียว รวมได้ \(360^\circ\) พอดี

รูปหลายเหลี่ยมด้านเท่ามุมเท่าที่ปูได้ลำพัง — มีเพียงสามชนิด: สามเหลี่ยมด้านเท่า (\(60^\circ\times6\)), สี่เหลี่ยมจัตุรัส (\(90^\circ\times4\)), หกเหลี่ยม (\(120^\circ\times3\))

ตัวอย่าง 3ยากเทเซเลชันผสม
จงหาทุกวิธีที่รูปสามเหลี่ยมด้านเท่า (\(60^\circ\)) และ รูปสี่เหลี่ยมจัตุรัส (\(90^\circ\)) มาชุมนุมรอบจุดเดียวได้พอดี
แล้วบอกว่าแบบใดปูเต็มระนาบได้จริง

แนวคิดและวิธีทำ

  1. ให้สามเหลี่ยม \(t\) รูป และจัตุรัส \(q\) รูป \[60t+90q=360\]
  2. หารด้วย 30: \(2t+3q=12\)
  3. \(q=0\Rightarrow t=6\) (สามเหลี่ยมล้วน)
  4. \(q=2\Rightarrow t=3\) ✓ (ผสม)
  5. \(q=4\Rightarrow t=0\) (จัตุรัสล้วน)
  6. \(q=1\) หรือ \(q=3\) ให้ \(t\) ไม่เป็นจำนวนเต็ม — ตกไป
  7. แบบผสม \(3\) สามเหลี่ยม \(+\ 2\) จัตุรัส ปูเต็มระนาบได้จริง และมีสองลายต่างกันตามลำดับการวางรอบจุด (3.3.3.4.4 กับ 3.3.4.3.4)

\((t,q)=(6,0),(3,2),(0,4)\) — แบบผสมคือ 3 สามเหลี่ยม + 2 จัตุรัส

ตัวอย่าง 4ประยุกต์ออกแบบลาย
ออกแบบลายเทเซเลชันจากรูปสี่เหลี่ยมจัตุรัสด้าน \(10\) ซม. โดยตัดส่วนหนึ่งออกจากด้านหนึ่งแล้วนำไปต่อที่ด้านตรงข้าม (เทคนิค "ตัด–เลื่อน")
(ก) พื้นที่ของรูปใหม่เท่าไร
(ข) รูปใหม่ปูระนาบได้หรือไม่ เพราะเหตุใด
(ค) ถ้าตัด–เลื่อนทั้งสองคู่ด้าน รูปใหม่ยังปูได้หรือไม่

แนวคิดและวิธีทำ

  1. (ก) การตัดส่วนหนึ่งออกแล้วนำไปต่อที่อื่น ไม่เปลี่ยนพื้นที่
  2. พื้นที่ \(=10\times10=100\) ตร.ซม. เท่าเดิม
  3. (ข) ปูได้ — เพราะส่วนที่หายไปจากด้านหนึ่ง ถูกเติมด้วยส่วนที่งอกออกมาจากด้านตรงข้ามของเพื่อนบ้าน
  4. รูปใหม่ยังเลื่อนขนานด้วยเวกเตอร์เดิม (\(10\) ซม. ในสองแนว) ไปปูต่อได้พอดี
  5. (ค) ยังปูได้ — หลักเดียวกันใช้กับทั้งสองแนว
  6. นี่คือเทคนิคที่ศิลปิน M.C. Escher ใช้สร้างลายสัตว์ ที่ปูเต็มระนาบ — รูปดูซับซ้อนแต่โครงยังเป็นตารางจัตุรัส

(ก) \(100\) ตร.ซม. (ไม่เปลี่ยน) (ข) ปูได้ เพราะส่วนที่ตัดกับส่วนที่ต่อเติมกันพอดี (ค) ปูได้

จงหาการแปลงเพียงชั้นเดียวที่เทียบเท่ากับ "สะท้อนรอบแกน \(x\) แล้วสะท้อนรอบเส้น \(y=x\)" (ทดสอบด้วยจุด \((1,0)\) และ \((0,1)\))

\((1,0)\): สะท้อนแกน \(x\) ได้ \((1,0)\) → สะท้อน \(y=x\) ได้ \((0,1)\)
\((0,1)\): สะท้อนแกน \(x\) ได้ \((0,-1)\) → สะท้อน \(y=x\) ได้ \((-1,0)\)
กฎที่ได้: \((1,0)\to(0,1)\) และ \((0,1)\to(-1,0)\)
นี่คือ \((x,y)\to(-y,x)\) = หมุน \(90^\circ\) ทวนเข็ม รอบจุดกำเนิด
ตรวจกฎ: สองเส้นตัดกันที่จุดกำเนิดเป็นมุม \(45^\circ\) จึงหมุน \(2(45^\circ)=90^\circ\) ✓

ยากหมุนสองจุด
ให้จุดเริ่ม \((x,y)\)
หมุน \(180^\circ\) รอบจุดกำเนิด: \((-x,-y)\)
หมุน \(180^\circ\) รอบ \((3,2)\): \((6-(-x),\,4-(-y)) =(x+6,\,y+4)\)
ได้ การเลื่อนขนาน ด้วย \(\langle6,4\rangle\)
ตรวจกฎ: มุมรวม \(=360^\circ\) ซึ่งเป็นตัวคูณของ \(360^\circ\) จึงได้การเลื่อนขนาน ✓
เวกเตอร์ \(=2\times\overrightarrow{O_1O_2}=2(3,2)=(6,4)\) ✓
