รูปเรขาคณิต มุม และพื้นที่

การสร้างรูปสี่เหลี่ยมด้านขนานแล้ววัดความยาวและมุม การสำรวจว่า ค่าใดเปลี่ยนและค่าใดไม่เปลี่ยนเมื่อลากจุด และการสำรวจสมบัติของวงกลม ด้วยเครื่องมือวัดในโปรแกรม

สี่เหลี่ยมด้านขนานพื้นที่จากการตัด–เลื่อนสมบัติวงกลมสำรวจด้วยการวัดแบบฝึกหัด 32 ข้อ

สี่เหลี่ยมด้านขนาน: สร้าง วัด และสำรวจ

เมื่อสร้างสี่เหลี่ยมด้านขนานให้ถูกต้องแล้วลากจุดยอด จะเห็นชัดว่าค่าบางค่าเปลี่ยน ค่าบางค่าไม่เปลี่ยน การแยกสองกลุ่มนี้ออกจากกันคือหัวใจของการสำรวจด้วยเรขาคณิตพลวัต

สิ่งที่วัดเมื่อลากจุดยอดอิสระเหตุผล
ความยาวด้านตรงข้ามเท่ากันเสมอสมบัติของสี่เหลี่ยมด้านขนาน
ขนาดมุมตรงข้ามเท่ากันเสมอสมบัติของสี่เหลี่ยมด้านขนาน
ผลรวมมุมประชิด\(180^\circ\) เสมอมุมภายในข้างเดียวกันของเส้นขนาน
ความยาวเส้นทแยงมุมเปลี่ยนไม่ใช่สมบัติที่ถูกบังคับ
ครึ่งเส้นทแยงมุมเท่ากันเสมอเส้นทแยงมุมแบ่งครึ่งกัน
พื้นที่เปลี่ยน (แต่ยัง \(=bh\))ขึ้นกับฐานและความสูงที่เปลี่ยนไป
เลื่อนจุดยอดไปตามเส้นขนาน (shear)

ถ้าสร้างสี่เหลี่ยมด้านขนานแล้ว บังคับให้จุดยอดบนเลื่อนได้เฉพาะ ตามเส้นที่ขนานกับฐาน จะเห็นว่า

  • ฐานไม่เปลี่ยน, ความสูงไม่เปลี่ยน → พื้นที่ไม่เปลี่ยน
  • ด้านเอียงยาวขึ้น, มุมเปลี่ยน, เส้นทแยงมุมเปลี่ยน

นี่พิสูจน์ด้วยสายตาว่าพื้นที่ขึ้นกับ \(b\) และ \(h\) เท่านั้น ไม่ขึ้นกับความยาวด้านเอียงเลย

ตัวอย่าง 1ปานกลางพื้นที่
สี่เหลี่ยมด้านขนานมีด้านยาว \(10\) ซม. และ \(6\) ซม. โดยความสูงที่ตั้งฉากกับด้านยาว \(10\) ซม. เป็น \(4.8\) ซม.
(ก) จงหาพื้นที่
(ข) จงหาความสูงที่ตั้งฉากกับด้านยาว \(6\) ซม.

แนวคิดและวิธีทำ

  1. (ก) พื้นที่ \(=b\,h=10\times4.8=48\) ตร.ซม.
  2. (ข) พื้นที่เดิมคำนวณจากฐานใดก็ได้ จึงตั้งสมการ \(6\times h_2=48\)
  3. \(h_2=8\) ซม.
  4. ตรวจความสมเหตุสมผล: \(h_2=8<10\) ✓ (ความสูงต้องน้อยกว่าด้านเอียงที่ยาว \(10\) ซม.)

(ก) \(48\) ตร.ซม.  (ข) \(8\) ซม.

ตัวอย่าง 2ยากสำรวจ
ใน GeoGebra สร้างสี่เหลี่ยมด้านขนาน \(ABCD\) แล้ววัดได้ว่า \(AC=13\) ซม., \(BD=11\) ซม. และ \(AB=8\) ซม.
จงหา \(AD\) โดยใช้เอกลักษณ์ของสี่เหลี่ยมด้านขนาน \[AC^{2}+BD^{2}=2(AB^{2}+AD^{2})\]

แนวคิดและวิธีทำ

  1. แทนค่า: \(13^{2}+11^{2}=2(8^{2}+AD^{2})\)
  2. \(169+121=2(64+AD^{2})\)
  3. \(290=128+2AD^{2}\)
  4. \(2AD^{2}=162\Rightarrow AD^{2}=81\Rightarrow AD=9\) ซม.
  5. ที่มาของเอกลักษณ์: ใช้กฎของโคไซน์ในสามเหลี่ยม \(ABC\) และ \(ABD\) โดยมุมประชิดรวมกันได้ \(180^\circ\) พจน์ \(\cos\) จึงหักล้างกันพอดี

\(AD=9\) ซม.

พื้นที่ของรูปสี่เหลี่ยมและรูปหลายเหลี่ยม

รูปสูตรพื้นที่ข้อควรระวัง
สี่เหลี่ยมด้านขนาน\(bh\)ใช้ความสูงตั้งฉาก ไม่ใช่ด้านเอียง
สี่เหลี่ยมคางหมู\(\tfrac12(a+b)h\)\(a,b\) ต้องเป็น ด้านขนาน คู่นั้น
รูปว่าว / รูปที่เส้นทแยงมุมตั้งฉาก\(\tfrac12 d_1 d_2\)ใช้ได้เฉพาะเมื่อเส้นทแยงมุม ตั้งฉากกัน
รูปสามเหลี่ยม\(\tfrac12 bh\) หรือ \(\sqrt{s(s-a)(s-b)(s-c)}\)เฮรอนใช้เมื่อรู้ด้านครบสามด้าน
รูปหลายเหลี่ยมบนพิกัดสูตรเชือกผูกรองเท้า (shoelace)ต้องเรียงจุดยอดไปทางเดียวรอบรูป
สูตรเชือกผูกรองเท้า

รูปหลายเหลี่ยมที่มีจุดยอด \((x_1,y_1),(x_2,y_2),\dots,(x_n,y_n)\) เรียงไปทางเดียวกันรอบรูป มีพื้นที่

\[K=\frac12\left|\sum_{i=1}^{n}(x_i y_{i+1}-x_{i+1}y_i)\right|\]

โดยกำหนด \((x_{n+1},y_{n+1})=(x_1,y_1)\)

สูตรนี้คือสิ่งที่ GeoGebra ใช้คำนวณพื้นที่รูปหลายเหลี่ยมให้เรา

ตัวอย่าง 3ยากเชือกผูกรองเท้า
จงหาพื้นที่ของรูปสี่เหลี่ยมที่มีจุดยอด \(A(1,1)\), \(B(7,2)\), \(C(6,6)\), \(D(2,5)\) (เรียงทวนเข็มนาฬิกา)

แนวคิดและวิธีทำ

  1. เขียนพิกัดเรียงกันแล้วย้อนกลับมาจุดแรก \[(1,1),(7,2),(6,6),(2,5),(1,1)\]
  2. คิดผลรวม \(\sum x_i y_{i+1}\) \(=1(2)+7(6)+6(5)+2(1)=2+42+30+2=76\)
  3. คิดผลรวม \(\sum x_{i+1} y_i\) \(=7(1)+6(2)+2(6)+1(5)=7+12+12+5=36\)
  4. \(K=\tfrac12|76-36|=\tfrac12(40)=20\) ตารางหน่วย
  5. ตรวจอีกวิธี แบ่งเป็นสองสามเหลี่ยมด้วยเส้นทแยงมุม \(AC\): \([ABC]=\tfrac12|1(2-6)+7(6-1)+6(1-2)|=\tfrac12|-4+35-6| =\tfrac{25}{2}\)
  6. \([ACD]=\tfrac12|1(6-5)+6(5-1)+2(1-6)|=\tfrac12|1+24-10| =\tfrac{15}{2}\)
  7. รวม \(=\tfrac{25}{2}+\tfrac{15}{2}=20\) ✓

\(20\) ตารางหน่วย

สำรวจสมบัติของวงกลมด้วยการวัด

เครื่องมือวัดในโปรแกรมทำให้ตั้งข้อคาดการณ์ได้เร็ว แต่ต้องจำไว้ว่าการวัดที่ตรงกันเป็นเพียง หลักฐาน ไม่ใช่การพิสูจน์ — ขั้นต่อไปคือหาเหตุผลว่าเหตุใดจึงเป็นเช่นนั้น

สิ่งที่ลองวัดข้อคาดการณ์ที่จะได้ทฤษฎีบทที่รองรับ
ลาก \(P\) ไปตามส่วนโค้ง แล้ววัด \(\angle APB\)ค่าไม่เปลี่ยนมุมในส่วนโค้งเดียวกันเท่ากัน
วัด \(\angle AOB\) เทียบ \(\angle APB\)\(\angle AOB=2\angle APB\)ทฤษฎีบทมุมในส่วนโค้ง
ลาก \(P\) เมื่อ \(AB\) เป็นเส้นผ่านศูนย์กลาง\(\angle APB=90^\circ\) เสมอมุมในครึ่งวงกลม
วัดมุมตรงข้ามของสี่เหลี่ยมแนบในวงกลมรวมกันได้ \(180^\circ\)สี่เหลี่ยมแนบในวงกลม
วัดเส้นสัมผัสสองเส้นจากจุดเดียวกันยาวเท่ากันเส้นสัมผัสจากจุดภายนอก
วัด \(PA\cdot PB\) กับ \(PC\cdot PD\) ของคอร์ดที่ตัดกันเท่ากันกำลังของจุด
กับดักของการวัดในโปรแกรม
  • การปัดเศษ — โปรแกรมแสดง \(90.00^\circ\) ได้แม้ค่าจริง เป็น \(89.996^\circ\) ให้เพิ่มทศนิยมก่อนสรุป
  • ตัวอย่างเดียวไม่พอ — ต้องลากจุดไปหลายตำแหน่ง รวมถึงตำแหน่งสุดขั้ว (เกือบเป็นเส้นตรง, เกือบทับกัน)
  • วัดผิดวัตถุ — มุมในวงกลมต้องมีจุดยอดบนวงกลมจริง ไม่ใช่จุดที่แค่อยู่ใกล้
ตัวอย่าง 4ประยุกต์ประยุกต์
นักเรียนสร้างวงกลมรัศมี \(5\) ในโปรแกรม แล้ววางจุด \(A(-4,3)\), \(B(4,3)\) บนวงกลม (ตรวจแล้วว่าอยู่บนวงกลมจริง)
(ก) จงตรวจว่า \(A,B\) อยู่บนวงกลมรัศมี \(5\) จุดศูนย์กลาง \((0,0)\) จริงหรือไม่
(ข) จงหาความยาวคอร์ด \(AB\) และระยะจากจุดศูนย์กลางถึง \(AB\)
(ค) จงหามุมที่จุดศูนย์กลางที่รองรับ \(AB\) (ปัดเป็นองศา)
(ง) ถ้าวาง \(P\) บนส่วนโค้งใหญ่ \(\angle APB\) เป็นเท่าไร

แนวคิดและวิธีทำ

  1. (ก) \(\sqrt{(-4)^{2}+3^{2}}=\sqrt{25}=5\) ✓ และ \(\sqrt{4^{2}+3^{2}}=5\) ✓
  2. (ข) \(AB=|4-(-4)|=8\) หน่วย (เพราะ \(y\) เท่ากัน)
  3. ระยะจากจุดศูนย์กลางถึงคอร์ด \(=|3-0|=3\) หน่วย
    ตรวจ: \(4^{2}+3^{2}=25=5^{2}\) ✓
  4. (ค) \(\sin\left(\tfrac{\theta}{2}\right)=\dfrac{4}{5}=0.8\)
  5. \(\tfrac{\theta}{2}=53.13^\circ\Rightarrow \theta\approx106.26^\circ\)
  6. (ง) มุมในส่วนโค้งใหญ่ \(=\tfrac12\theta \approx53.13^\circ\)

(ข) \(AB=8\), \(d=3\)  (ค) \(\approx106^\circ\)  (ง) \(\approx53^\circ\)
